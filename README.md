# Tarea8_Maquinas-Virtuales

A continuacion se muestra de forma práctica y paso a paso la creación e instalación de tres máquinas virtuales (Rocky Linux, Kali Linux y Windows), su conexión a una red virtual común y la verificación de la comunicación entre ellas. Incluye los comandos y parámetros usados en QEMU/NetworkManager, las pruebas de conectividad (pings) y las soluciones a problemas comunes.
